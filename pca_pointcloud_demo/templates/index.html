What is PCA?
Principal Component Analysis finds the directions of maximum variance in the point cloud.
  • Red Vector (PC1): Direction of most spread.
  • Green Vector (PC2): 2nd most spread, orthogonal to PC1.
  • Blue Vector (PC3): 3rd most spread, orthogonal to both.
After finding the 3 vectors, we use them for:
  1. Dimensionality Reduction: Discarding the smallest vector (PC3) and projecting 3D points onto the 2D plane (PC1 & PC2) to compress data.
  2. Alignment (Canonicalization): Multiplying the points by the eigenvectors rotates the cloud to a standard orientation, standardizing inputs before neural networks (PointNet).
  3. Bounding Boxes: The vectors define the optimal orientation for a tight 3D Oriented Bounding Box (OBB) around objects like cars.
  4. Geometric Features: The relative sizes of eigenvalues reveal if a local point cluster is linear (a wire), planar (a wall), or spherical (a bush).

PCA vs PointNet

Feature PCA PointNet
Type Statistical/Linear Deep Learning
Computation Fast, CPU-based Heavy, needs GPU
Use Case Alignment, Normals Classification, Seg.
Features Global axes Local & Global learned features

Intuition: PCA mathematically finds the bounding box/axes of the whole cloud. PointNet processes each point independently using MLPs, then aggregates them (Max Pooling) to "understand" complex, non-linear shapes (like a chair vs. a table) that PCA would just see as similar blobs of variance.
